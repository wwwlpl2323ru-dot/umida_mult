Проверь изменения в проекте перед коммитом по этому чек-листу. Пройдись по `index.html`, `css/styles.css`, `js/script.js` и сообщи о найденных проблемах (или подтверди, что всё ок), не делая правок без согласования.

## Чистота кода

- [ ] В HTML нет лишних/дублирующихся атрибутов, не используемых классов, незакрытых тегов.
- [ ] У всех инлайн-SVG с `<defs>`/градиентами уникальные `id` по всему документу (дублирование `id` ломает рендер).
- [ ] В CSS нет дублирующихся правил и неиспользуемых селекторов; фигурные скобки сбалансированы (`{` = `}`).
- [ ] Новые цвета/радиусы/тени/шрифты берутся из переменных `:root`, а не хардкодятся заново.
- [ ] Новые классы названы в духе существующих (`.acc`, `.gcard`, `.fcard`, `.chip`, `.prop` и т.п.), без смешения систем именования.
- [ ] JS не дублирует логику, аккордеоны/меню переключаются через классы (`.is-open`, `.active`, `.is-visible`), без лишних инлайн-стилей.
- [ ] Анимации и декоративные элементы (`.prop`, `.chip`, `.float-deco`, любые `@keyframes`) отключаются через `@media (prefers-reduced-motion: reduce)`.

## Мобильная адаптация

- [ ] Страница проверена на ширинах ~360–420px (телефон), ~768px (планшет) и ≥1200px (десктоп).
- [ ] Текст не обрезается и не вылезает за пределы экрана, нет горизонтального скролла.
- [ ] Бургер-меню (`#burger` / `#navLinks`) корректно открывается/закрывается и не перекрывает контент.
- [ ] Изображения (hero, about, галерея персонажей) не обрезаются критично и сохраняют пропорции.
- [ ] Кнопки и интерактивные элементы достаточно крупные для тапа (не наезжают друг на друга).

## Ссылки

- [ ] Ссылки на тарифы ведут на актуальные адреса оплаты (Tribute/Telegram) и открываются в новой вкладке (`target="_blank" rel="noopener"`).
- [ ] Ссылки на Telegram-канал и личный контакт (`@umidanishanowa`) корректны и совпадают во всех местах (hero, prices, final, footer).
- [ ] Якорные ссылки навигации (`#future`, `#how`, `#program`, `#reviews`, `#prices`, `#faq`) указывают на существующие секции с такими `id`.
- [ ] Нет битых/заглушечных ссылок (`#`, `javascript:void(0)`) на финальных CTA-кнопках.
- [ ] Пути к изображениям и `favicon.svg` корректны и файлы существуют в `assets/`.
