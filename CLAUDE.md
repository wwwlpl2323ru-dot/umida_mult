# CLAUDE.md

## Проект

Одностраничный лендинг «ИИ-мультики · Курс Умиды» — продающая страница курса по созданию ИИ-роликов (Gemini, Grok, ElevenLabs, CapCut). Цель страницы — привести к оплате одного из двух тарифов через Tribute/Telegram.

## Стек

- Чистые **HTML/CSS/JS**, без сборщиков, фреймворков и зависимостей (no npm, no build step).
- Шрифты: **Unbounded** (заголовки) + **Manrope** (текст) — подключены через Google Fonts в `<head>`.
- Открывается прямо как файл или через Live Server. Деплой — статика (GitHub Pages/Netlify/любой хостинг).

## Структура

```
index.html            ← вся разметка одной страницы (секции: hero, gallery, future, how, program, author, reviews, prices, faq, final, footer)
css/styles.css        ← все стили, design-токены в :root
js/script.js          ← бургер-меню (#burger/#navLinks), аккордеоны (.acc/.acc-head/.acc-body/.plus), scroll-reveal (.reveal/.is-visible через IntersectionObserver)
assets/favicon.svg    ← иконка-клубничка
assets/img/*.jpg      ← hero.jpg, about.jpg, character-1..5.jpg
README.md
```

## Дизайн-токены (css/styles.css → :root)

- Цвета: `--strawberry #FF4D77`, `--strawberry-dark #E11D54`, `--strawberry-deep #C2174A`, `--coral #FF7A6B`, `--gold #E6B24C` / `--gold-dark #C9961F`, `--leaf #46B07A`, `--pearl #F3E9DC`, `--text #2A1320`, `--text-light #6E5560`, `--blush`, `--ink`.
- Фон — тёплый градиент персик → крем → розовый (`--bg-gradient`), с лёгкой анимацией `bgShift`.
- Радиусы (`--radius-lg/md/sm`), тени (`--shadow-soft/--shadow-card`), `--transition: 0.3s ease`.

## Правила стиля

- Все новые цвета/радиусы/тени брать из существующих переменных в `:root`, а не хардкодить новые значения — если нужен новый токен, добавлять его в `:root` и использовать через `var(...)`.
- Имена классов — короткие, в существующем стиле текущей разметки (`.acc`, `.gcard`, `.fcard`, `.prop`, `.chip`, `.cap`, `.t`/`.s` и т.п.). Не вводить новую систему именования (BEM и т.п.) для уже существующих секций.
- Декоративные элементы (`.prop`, `.chip`, `.float-deco`) и любые CSS-анимации должны быть отключены/безопасны через `@media (prefers-reduced-motion: reduce)`.
- Инлайн SVG с `<defs>`/градиентами — у каждого градиента в документе должен быть **уникальный `id`** (id градиентов резолвятся глобально по всему HTML-документу, дублирование ломает рендер других иконок).
- Мобильная адаптивность обязательна для любых новых блоков — добавлять медиа-запросы по аналогии с существующими breakpoint'ами (380–960px).
- JS-логика — без библиотек, vanilla JS, аккордеоны и меню переключаются через классы (`.is-open`, `.active`, `.is-visible`), а не инлайн-стилями (кроме `max-height` в аккордеонах).
- Изображения — `assets/img/`, в README указаны рекомендуемые размеры/вес; при замене сохранять те же имена файлов.

## Что нельзя делать

- Не добавлять сборщики, package.json, фреймворки (React/Vue и т.п.) — проект должен оставаться статическим HTML/CSS/JS.
- Не менять ссылки оплаты тарифов и контакты без явного запроса пользователя (это коммерческие данные: цены, Tribute/Telegram-ссылки).
- Не трогать `.gitignore`/git remote и не пушить в `main` без явного запроса пользователя — коммиты делать с понятным сообщением на русском (как в истории: «Обновил тексты, цены и ссылки оплаты» и т.п.).
- Не переименовывать существующие CSS-классы/ID без проверки всех мест использования в `index.html` и `js/script.js` (особенно `#navLinks`, `#burger`, `.acc`/`.acc-head`/`.acc-body`/`.plus`, `.reveal`).
- Не удалять `prefers-reduced-motion` блоки и не оставлять «голые» анимации без них.
- Не использовать emoji в коде/комментариях сверх того, что уже есть в контенте (эмодзи — часть текста лендинга, не декор кода).
